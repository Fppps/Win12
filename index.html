About

Built from the system outward.

The project is organized around explicit components, visible behavior, and direct control over how each part of the software works.

01 / STRUCTURE

Modular by design

Major behaviors are separated into focused files and data layers instead of being buried inside one catch-all runtime.

02 / LOCALITY

Browser-native execution

The workspace is designed to run directly in the browser, keeping the implementation inspectable and close to the user.

03 / CONTROL

Behavior you can inspect

Rules, model state, interface behavior, and supporting data are kept visible so the system can be changed deliberately.

Why it exists

VilotGRI was started by WATS (Whitty At The South) as a self-directed software project with one recurring idea: build useful systems without making the implementation feel inaccessible.

“As the founder of Avlaora™, I'm not here to force users to use anything behind a paywall; I'm here to previde available & free apps to any person at any time.”Core founding principle

VilotNI 2 / Release

A look at the next system.

VilotNI 2 releases on September 30 with a larger reasoning architecture, stricter answer confidence, expanded language handling, persistent conversation features, and a cleaner product interface.

Release date
Sept 30
2026
01
6M-neuron RSL core
A substantially larger recurrent/self-learning runtime that keeps the existing learned-state architecture while expanding the model's working capacity.
02
Confidence-gated responses
Responses are evaluated before they are shown. Lower-confidence candidates remain internal while the system continues searching for a stronger answer.
03
Focused evidence search
Query planning, evidence retrieval, and candidate ranking are separated so straightforward prompts can reach relevant knowledge before broader recovery search is needed.
04
Language rule data
Grammar, punctuation, query patterns, semantic relations, context behavior, and lexical definition indexes now live in dedicated rule/data layers.
05
Context-aware follow-ups
Short prompts such as “Why?” can resolve against the active conversation instead of being treated like incomplete standalone questions.
06
Product interface
Saved chats, account preferences, model defaults, appearance settings, and a unified response presentation are being brought into the same workspace.
VilotNI 2 is the current release line. Development will continue after launch, and this page reflects the September 30 public release.
